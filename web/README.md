# 🎬 MovieVIP — Frontend-only хувилбар (`web/`)

Энэ бол **сервер шаардахгүй**, зөвхөн browser дээр ажилладаг хувилбар. Бүх мэдээлэл (кино, хэрэглэгч, VIP) нь тухайн **браузерын localStorage**-д хадгална.

## ▶️ Хэрхэн ажиллуулах

**Хамгийн хялбар:** `web/index.html` файлыг браузераар нээхэд л ажиллана.

Эсвэл жижиг сервер (зарим браузер file:// дээр хязгаартай):
```bash
cd web
python3 -m http.server 8080
# http://localhost:8080
```

## 🌐 Үнэгүй host хийх (домэйнтэй, HTTPS-тэй)

`web/` фолдер бол цэвэр static тул дараах газруудад **үнэгүй, автомат HTTPS-тэй** тавьж болно:

- **GitHub Pages** — repo → Settings → Pages → folder `/web` сонгоно
- **Netlify** — `web/` фолдерийг чирж оруулна (drag & drop)
- **Cloudflare Pages / Vercel** — GitHub холбоод `web/`-г output болгоно

Домэйн: тухайн платформын "Custom domain" хэсэгт өөрийн домэйноо холбоод DNS-ээ зааврынх нь дагуу тохируулна. SSL автоматаар идэвхжинэ.
